# person schema · 人物蒸馏

> 用于蒸馏**真实人物**或**虚构角色**。产出物是「这个人怎么想、怎么判断、怎么说话」的可运行认知骨架。

适用对象：在世/已故公众人物、历史人物、虚构角色（小说/影视/游戏）。
不适用：一个话题、一份文档 → 见 `schema-topic.md` / `schema-document.md`。

## 一、维度划分（6 维）

维度命名与编号直接写入 `DISTILLATE.md` frontmatter 的 `dimensions`，顺序对应 `research/` 文件编号。六维须**互斥、穷尽、可并行**（见 `distillation-framework.md` 第八节）。

| 编号 | 维度 | 文件 | 搜索/提取目标 |
|------|------|------|--------------|
| 01 | 著作 | `01-writings.md` | 本人署名或本人主导产出的长文本：书、论文、年报致股东信、专栏、内部备忘录 |
| 02 | 对话 | `02-conversations.md` | 有来有回的互动文本：访谈、播客、问答、庭审记录、书信往来 |
| 03 | 表达 | `03-expression-dna.md` | 语言表层特征：句法、修辞、口癖、幽默方式、类比库 |
| 04 | 他者 | `04-external-views.md` | 他人对 TA 的描述、评价、批评，以及 TA 对具体他人的评价 |
| 05 | 决策 | `05-decisions.md` | 可追溯的真实选择：下注、拒绝、退出、人事、时间与金钱分配 |
| 06 | 时间线 | `06-timeline.md` | 生平事件与**立场演化**的对应关系，标注早期/近期 |

### 01 著作
- **提取重点**：反复出现的主张（去水三问第 2 问：出现 ≥3 次才是真信念）、自创术语、对同行的点名批评。
- **常见陷阱**：❌ 把代笔/编辑润色后的文字当作表达 DNA 的证据（著作只能证主张，不能证口语风格）；❌ 把再版时后加的修订混入初版立场。

### 02 对话
- **提取重点**：**被追问时的反应**——即兴类比、回避模式、反问、承认无知的边界。对话是唯一能观察到「思考过程」而非「思考结果」的维度。
- **常见陷阱**：❌ 只收金句，丢掉提问与上下文；❌ 忽略访谈者的立场偏置（敌意访谈里的强硬 ≠ 日常性格）。

### 03 表达
- **提取重点**：可计数的语言特征，见下文「表达DNA 量化」。
- **常见陷阱**：❌ 用「幽默风趣」「深入浅出」这类无法证伪的形容词收尾；❌ 把翻译腔当作本人风格（非母语素材须标注语言）。

### 04 他者
- **提取重点**：**同一事件的不同叙述版本**——这是矛盾三类中「领域性矛盾」的主要来源；对手的批评比盟友的赞美信息量高。
- **常见陷阱**：❌ 只收正面评价；❌ 把二手分析（C 级）写成一手直引（A 级）。

### 05 决策
- **提取重点**：**决策时刻的可选项**。不知道当时还有什么别的选择，就不知道这个决策意味着什么。记录「拒绝过什么」比记录「做了什么」更有信息量。
- **常见陷阱**：❌ 结果论——用事后成败反推决策质量（塔勒布明确反对，见「反脆弱」）；❌ 只收成功案例，丢掉失败与后悔。

### 06 时间线
- **提取重点**：立场**改变**的节点与触发事件。时间性矛盾靠本维度定位。
- **常见陷阱**：❌ 把生平流水账当时间线——时间线只保留「与立场变化挂钩」的事件；❌ 用近期立场覆盖早期立场（演化轨迹本身是资产）。

## 二、schema 专属正文段

插入位置：`DISTILLATE.md` 正文的「核心骨架」之后、「矛盾与张力」之前。顺序如下：

```markdown
## 身份与时间线
[一段话定位：是谁、活跃期、坐标系。随后是「立场演化表」：时期 | 主张 | 触发事件 | 信度]

## 心智模型
### <模型名>
**一句话**：…
**证据**：…（≥2 个不同场景，标注信度等级）
**生成力**：能推断出什么新立场
**局限**：什么情况下失效

## 决策启发式
| 场景 | 启发式（可执行的一句话） | 反例/失效条件 | 信度 |

## 表达DNA
[量化，见第三节]

## 价值观与反模式
**排序**：价值冲突时 TA 优先牺牲哪个、保住哪个
**反模式**：TA 明确反对的行为与论证方式（黑名单）

## 智识谱系
[受影响于谁 / 影响了谁 / 与谁构成对立轴，每条标注是本人承认还是他人归类]
```

**与通用骨架的关系**：本段中的「心智模型」「表达DNA」即通用骨架「心智模型 / 核心框架」与「表达特征」两段在 person schema 下的**具体化**，不重复写两份，直接按本节格式落地。

**硬性要求**：
- 心智模型条目数 3-7 条，全部须过**三重验证**（跨域复现 / 生成力 / 排他性）。
- 「价值观与反模式」必须给出**排序**，不允许并列罗列。❌「既重视 A 又重视 B」是无信息量的写法；✅「A 与 B 冲突时选 A，代价是牺牲 B」。
- 智识谱系每条须标注信度：本人承认 = A/B，他人归类 = C。

## 三、表达DNA 必须量化

❌ 不合格：「语言犀利，善用类比，富有幽默感。」
✅ 合格：三项都可计数、可被他人复核。

| 项 | 定义 | 记法 | 例（芒格） |
|----|------|------|-----------|
| **句式指纹** | 可统计的句法特征 | 平均句长 / 疑问句占比 / 类比密度（每千字个数）/ 转折词偏好 | 短断言句为主；类比密度高；高频使用「反过来想」式倒置 |
| **风格标签轴** | 4 组对立轴上的取值 | 冷↔热 / 抽象↔具象 / 断言↔试探 / 书面↔口语 | 冷、具象、断言、口语 |
| **禁忌词 / 口癖** | 高频口癖（白名单）与从不使用的词（黑名单） | 各列 5-10 条，附出现频次 | 口癖：「lollapalooza」「反过来想」；禁忌：不用时髦管理术语 |

**量化方法**：直接复用 `distillation-framework.md` 第二节**去水三问**的第 2 问——**重复次数是最强的去水信号**。口癖 = 高频重复项；风格标签 = 对全部素材的统计倾向，不是挑最精彩的一段。样本 <10 条时标注「样本不足，风格标签为推测」（D 级）。

## 四、在世非公众人物的边界

蒸馏**在世非公众人物**（同事、亲友、用户本人、私域社群成员）时：

| 规则 | 说明 |
|------|------|
| **授权前置** | 未获本人同意，不建立档案；用户蒸馏自己除外 |
| **只蒸馏公开/授权素材** | 私人聊天记录、邮件、未公开录音默认排除，除非本人明确授权 |
| **主动沉默 ≠ 信息缺失** | 本人刻意回避的话题，标注「主动不公开」（见 `distillation-framework.md` 第六节），**不替他生成立场** |
| **降级输出** | 档案用于内部分析，不进入公开分发；`title` 不加宣传性修饰 |
| **可撤回** | 本人要求删除时，整目录删除并记录变更 |

公众人物不适用本条；但**家庭生活、健康、未公开的私人关系**同样按「主动不公开」处理。

## 五、质检

- [ ] 六维都有 `research/` 底稿，`coverage` 无一项为 0？低覆盖维度标了 `partial`？
- [ ] 心智模型 3-7 条，每条过了三重验证，且每条带信度？
- [ ] 表达DNA 三项（句式指纹 / 风格标签轴 / 禁忌词口癖）都是可计数量化，无形容词凑数？
- [ ] 矛盾分了类型（时间性 / 领域性 / 本质性张力），且**没有调和**？
- [ ] 立场演化表至少有一个「改变」的节点？全篇立场不变通常意味着素材太薄。
- [ ] 价值观给了排序，不是并列？
- [ ] D 级占比 <20%，且都显式写了「（推断）」？
- [ ] `gaps` 非空（人物档案极少真的无缺口）？
