# topic schema · 话题蒸馏

> 用于蒸馏**一个领域或议题**（价值投资、反脆弱决策、产品克制）。产出物是「这个议题上，哪些是共识、分歧在哪、怎么用」的可运行认知地图。

适用对象：学科分支、方法论、行业议题、思维框架、实践领域。
与 person schema 的根本差异：**话题的价值在分歧，人物的价值在独特**。

## 一、维度划分（6 维）

| 编号 | 维度 | 文件 | 搜索/提取目标 |
|------|------|------|--------------|
| 01 | 领域共识 | `01-consensus.md` | 教科书级、被各派共同接受的地基主张 |
| 02 | 流派分歧 | `02-schools.md` | 成体系的对立阵营：各自的核心主张、代表作品、论证路径 |
| 03 | 关键概念 | `03-concepts.md` | 术语的精确定义与**各派定义差异** |
| 04 | 经典案例 | `04-cases.md` | 被反复引用的正例与反例，以及各派对同一案例的不同解读 |
| 05 | 争议前沿 | `05-frontier.md` | 尚未定论、正在被争夺的问题 |
| 06 | 演进脉络 | `06-evolution.md` | 议题的历史：什么问题催生了它，主张如何随环境变化 |

### 01 领域共识
- **提取重点**：**最低争议底线**——哪怕最激进的一派也不会否认的东西。共识是后续所有分歧的坐标系。
- **常见陷阱**：❌ 把「多数人这么说」当共识（要问：有没有成体系的反例）；❌ 共识条目写太多，档案退化成教科书目录。

### 02 流派分歧
- **提取重点**：**分歧的根源**——两派是在事实上不一致，还是在价值排序上不一致？后者不可调和，必须保留。
- **常见陷阱**：❌ 和稀泥式调和（「其实两者互补」）；❌ 把某一派写成「正确」，另一派写成「过时」——除非该派确实已被证伪，且须给出证伪证据。

### 03 关键概念
- **提取重点**：**同词不同义**。同一术语在各派定义不同，是分歧的常见伪装。
- **常见陷阱**：❌ 只给一个「标准定义」——那通常就是某一派的定义被当成了通用定义。

### 04 经典案例
- **提取重点**：**一例多解**。同一个案例（如长期资本管理公司 LTCM 的崩盘）在各派叙事里结论相反，这比案例本身更有信息量。
- **常见陷阱**：❌ 把案例当证据而非当**分歧的战场**；❌ 只收成功案例。

### 05 争议前沿
- **提取重点**：正在被争夺的问题、新出现的反例、尚未被主流吸收的少数派。
- **常见陷阱**：❌ 把前沿写成「未来展望」式的空话；❌ 忽略时间戳——前沿有时效性，须标 `updated`。

### 06 演进脉络
- **提取重点**：议题的**问题起源**（它当初要解决什么）与**范式转移**节点。
- **常见陷阱**：❌ 写成大事年表；只保留「主张发生改变」的节点。

## 二、三重验证 → 共识度分级

人物蒸馏用**排他性**判断价值：「不是所有聪明人都这样想」。
**话题蒸馏中排他性失效**——话题里没有「某个人独有的视角」，一个主张要么被广泛接受，要么被某派坚持。因此第三重验证被替换为**分歧度**：

| 三重验证（原） | topic schema 中的改造 |
|---------------|---------------------|
| 验证 1 跨域复现 | **跨案例复现**：同一主张在 ≥2 个独立案例/流派中被独立提出 |
| 验证 2 生成力 | **保留**：能否推断出素材未覆盖的新场景该怎么判断 |
| 验证 3 排他性 | **→ 分歧度**：该主张在共识-分歧轴上的位置 |

### 共识度四级（取代排他性判定）

| 级别 | 名称 | 定义 | 在档案中的位置 |
|------|------|------|---------------|
| **甲** | 领域共识 | 各派均接受，教科书级 | 「框架总览」的地基，低信息量但可靠 |
| **乙** | 主流 | 多数接受，存在有力反对 | 「框架总览」主体 |
| **丙** | 流派分歧 | ≥2 派各自成体系地坚持，且各有代表案例 | 「流派对比表」，**档案最有价值的部分** |
| **丁** | 争议前沿 | 少数派、尚未定论 | 「争议前沿」段 |

**判级规则**：
- 甲的条目**不得进「核心骨架」**——正确但无信息量，与人物蒸馏中「要重视用户」同类。共识进「框架总览」当背景。
- **丙是骨架的主力**：一份话题档案的浓度，取决于它讲清了多少组分歧，而不是罗列了多少共识。
- 分级结果写入 `research/02-schools.md`，并在 `DISTILLATE.md` 每条条目后标注（甲/乙/丙/丁）。

**信度四级（A/B/C/D）仍然照常使用**，它衡量的是**来源**而非**争议度**，两者正交：

| 来源类型 | 典型信度 |
|---------|---------|
| 原始论文 / 一手数据 / 当事人自述 | A |
| 权威综述转述的原始观点 | B |
| 教科书、评论文章、二手总结 | C |
| 蒸馏者跨流派的模式推断 | D |

> 例：塔勒布本人写「预测系统性失效」= A 级来源 + 丙级（流派分歧，与风险价值 VaR 阵营对立）；某财经媒体总结「反脆弱就是抗压」= C 级来源 + 甲级（且是误读）。

## 三、schema 专属正文段

插入位置：`DISTILLATE.md` 正文的「核心骨架」之后、「矛盾与张力」之前。

```markdown
## 框架总览
[议题的一句话定义 + 坐标系：本议题在解决什么问题。随后 3-7 条核心骨架，每条带（共识度级别 + 信度）]

## 流派对比表
| 流派 | 核心主张 | 关键概念（其定义） | 代表案例 | 与对立派的分歧根源 | 信度 |

## 概念词典
| 术语 | 通用定义 | 各派差异 | 常见误用 | 信度 |

## 案例库
### <案例名>
**事实**：…
**各派解读**：A 派 → …；B 派 → …（**保留分歧，不裁决**）
**信度**：…

## 适用边界
[本议题的框架在什么条件下有效、什么条件下失效；跨领域迁移的限制]
```

**注意**：通用骨架中的「表达特征」段在 topic schema 下写作 **「语域与风格」**——话题没有语言指纹，只需标注**该领域的语域**（学术 / 从业者黑话 / 大众科普）与**叙述风格要求**（中性、专业、不用第一人称、不制造金句）。这一段的用途是：话题档案会喂给**主题型 persona**，语域标注决定 persona 用什么口吻谈这个议题。

**硬性要求**：
- 「框架总览」中的骨架条目 3-7 条，**至少一半是丙级（流派分歧）**。
- 「流派对比表」至少 2 派，每派须有代表案例，否则是稻草人。
- 「适用边界」必须写，且要给出**失效条件**——❌「适用于大多数情况」是无信息量的写法。

## 四、质检

- [ ] 骨架里**没有**甲级（领域共识）条目充数？
- [ ] 流派对比表里每一派都有真实代表与案例，没有稻草人？
- [ ] 概念词典记录了**各派定义差异**，而不是单一「标准定义」？
- [ ] 案例库里至少有一个「一例多解」的案例？
- [ ] 分歧被保留，没有出现「其实两者互补」式调和？
- [ ] 「语域与风格」写的是语域标注，没有硬造语言指纹？
- [ ] 「适用边界」给了明确失效条件？
- [ ] 争议前沿段带时间戳（`updated`），D 级占比 <20%？
