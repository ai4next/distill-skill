# 生成算子

> 判定线是「拿产物去回答素材里没直接出现过、但相关的新问题」。本文件回答一个
> 前面的方法论都没回答的问题：**那份「能回答新问题的结构」，具体是怎么长出来的？**

## 一、问题：全套方法论都是过滤器

去水三问（删）、信度四级（降级）、三重验证（筛）、张力分类（不许抹平）、
缺口标注（不许补）——**每一个动作都在防，没有一个是生成**。过滤器只能保住已有的信息，
不能创造信息。所以「生成力」在流程里一直是**只被测量、不被生产**的。

Phase 4「档案合成」是生成力真正诞生的地方，而它在 SKILL.md 的流程表里只有一行
「写 DISTILLATE.md + 封存哈希」。本文件补上那一行的内容。

## 二、关键纪律：算子产出的是**结构**，不是结论

这是最容易搞错的一点，也是本文件存在的最大理由。

**❌ 错误理解**：生成算子 = 在档案里多写几条「推断出来的新结论」。

这行不通，而且会撞上三道墙：

| 墙 | 冲突 |
|---|---|
| `D ≤ 20%` | 推出来的结论都是 D 级（素材里没有），写多了直接超标 |
| 守卫 3（只许删改不许新增断言） | 精炼阶段禁止新增断言，靠推断堆结论正是它要堵的 |
| 反模式 #11（灌水刷浓度） | 结论看着像条目，但没有素材支撑，是变相灌水 |

**✅ 正确理解**：算子把**推出新结论所必需的结构**写进档案；新结论在**被问到时**
由读者（或答题 agent）现场推出来。

打个比方：档案不是一本「问题-答案」手册，是一套**可运行的规则**。
你往规则里塞答案，规则就死了；你把规则本身写清楚，它才能回答没写过的问题。

所以下面每个算子的「产出」一栏写的都是**结构**——价值排序、适用边界、条件差异、
跨域复现的证据——它们的信度是 A/B/C（素材直接支持或可归纳），**不是 D**。

## 三、五个算子

### 算子 1 · 张力外推（主力）

**输入**：一条**本质性张力**（补全语境后依然对立的真矛盾，见 framework §五）。

**动作**：问「冲突时优先牺牲哪个、保住哪个」→ 得到**价值排序** →
拿这个排序去套一个素材里没出现过的场景。

**产出**：把**价值排序**写进档案（`## 价值观与反模式` 的「排序」、或心智模型的「局限」），
**不要**把外推出来的那个具体立场写进去。

```markdown
<!-- 档案里写这个（结构，可溯源） -->
**排序**：当确定性与收益率冲突时，优先牺牲收益率、保住确定性（A · sources/notes/n1.md）

<!-- 不写这个（结论，是 D 级推断，写多了超标） -->
他面对 AI 泡沫会减持高估值标的。
```

**自检**：读档案的人拿到这条排序，能不能自己推出「面对 AI 泡沫他会怎么做」？
能 → 结构写对了。推不出 → 排序写得太笼统，补上「代价是牺牲什么」。

> 这是 framework §5.2「知道排序，才能推断未覆盖场景该怎么选」的**操作化**。
> 那句话一直写在论证里，这里把它变成流程里的一步。

### 算子 2 · 结构迁移

**输入**：维度 A 里的一个框架 / 心智模型，以及维度 B 里的一个具体案例。

**动作**：把 A 的框架**套到** B 的案例上，问「用它看会得出什么」。

**产出**：写进**心智模型条目的「证据」栏**——因为跨域适用正是
「验证 1 跨域复现」要的证据（framework §四）。

```markdown
**证据**：在产品选型与人事任免两处都先问可逆性（A）；在时间分配上同样保留冗余（B）
```

这条证据本身就是生成力的来源：读者看到「三个领域都适用」，才能把它用到第四个领域。

**自检**：这个框架在 A 和 B 两处的用法**真的同构**吗？只是词面像、结构不同构 → 丢弃。
牵强的迁移是「编造模式」，比不写更糟。

### 算子 3 · 边界外推

**输入**：一条**低阶张力**（时间性 / 领域性）或心智模型的「局限」栏。

**动作**：问「条件变了会怎样」——补全语境后张力消失的那个条件，反过来就是**失效边界**。

**产出**：写进**「局限」/「适用边界」**栏（framework §5.2：低阶张力揭示**条件的边界**）。

```markdown
**局限**：当机会窗口极短、可逆选项不存在时，该框架会退化为犹豫。
```

**自检**：边界是**具体的**还是「适用于大多数情况」？后者是无信息量的写法
（`schema-topic.md` 硬性要求给失效条件）。

### 算子 4 · 反问题

**输入**：整份骨架。

**动作**：不问「他主张什么」，问「他会**问**什么」；不问「文档说了什么」，
问「什么证据能推翻它」。

**产出**：写进**「心智模型」的「一句话」**——把主张重写成可执行的提问形式。

```markdown
**一句话**：决策前先问这一步能不能退回来，能退的才值得试。
```

提问形式比陈述形式生成力强得多：陈述只能被复述，提问能被**套用到新场景**。

**自检**：换个不熟悉素材的人，拿着这句话能不能去判断一个全新的决策？

### 算子 5 · 组合

**输入**：两条独立的心智模型。

**动作**：问「两者相乘得到什么」——单独用任何一个都得不出、必须同时用才成立的那个立场。

**产出**：写进**心智模型条目的「生成力」栏**（该栏本来就要求写「能推断出什么新立场」）。

```markdown
**生成力**：可推断他对不可逆的公开承诺会异常谨慎，即使收益看起来很高。
```

**自检**：这条生成力**只靠一条模型**就能得出吗？能 → 它不是组合，是复述，删掉。
组合的价值恰恰在于它超出任一单条模型。

## 四、和「复述」的分界线

五个算子都可能在不知不觉中退化成复述。判据只有一条：

> **推出来的东西，能不能指回 ≥2 条骨架条目？**

只能指回 1 条 → 你只是把那条骨架换个说法（复述）。
指不回任何一条 → 你用的是模型自己的常识，不是这份档案（那正是
`quality-scorecard.md` 要防的「用常识冒充档案的生成力」）。

这条判据不是本文件发明的——评分卡要求答题 agent「答对了但说不出用了哪条骨架 → 该题减半」。
**档案作者的义务，就是让读者指得回去。**

## 五、与 Phase 的关系

| Phase | 算子在哪一步用 |
|-------|--------------|
| 2 · 分维度提炼 | 算子 2（结构迁移）、算子 4（反问题）——各维度内部就能做 |
| 3 · 交叉验证 | 算子 1（张力外推）、算子 3（边界外推）——需要跨维度看张力 |
| 4 · 档案合成 | 算子 5（组合）——心智模型条目成型时 |

**顺序不能反**：张力外推依赖 Phase 3 分好的张力类型；跳过 Phase 3 直接外推，
推的是没分类的笼统印象。
