# 综合档案规范（Meta-Synthesis）

> 把 N 份已有档案综合成一份「这个领域的共识与分歧」——蒸馏的蒸馏。

## 一、为什么是 topic schema 而不是新 schema

综合档案**沿用 `topic` schema**，`sources[]` 存的是那 N 份档案。

**不新增 schema 的三个理由**：

| 理由 | 说明 |
|------|------|
| 字段无法诚实填写 | `quality_check.py` 的 `REQUIRED_FIELDS` 要求 `sources_primary` / `compression_ratio` 等字段。若为新 schema 硬造，等于**编造字段值**——违反铁律3；若不填，静态质检必然 FAIL |
| 语义天然对口 | `schema-topic.md` 已经有「领域共识 / 流派分歧」，并明确「话题的价值在分歧」——这正是综合档案要产出的一切 |
| 契约零成本 | `schema_version` 保持 1，所有既有消费者与脚本无需改动 |

**综合档案与普通 topic 档案的唯一区别**：多一个 `## 综合` 段。

---

## 二、信度继承规则（解决「信度不复合」）

普通档案的信度四级衡量的是「这条主张在其素材中的证据强度」。综合档案的条目源头是别的档案，若机械套用会全部退化成 B（一手转述），而「涌现结论」必然是 D——**恰好落进 `D > 20%` 的判 0 区间**。

**规则**：

> **综合条目的信度 = 来源档案中该条目的信度。**
> 出处标注为「档案 X §条目名」，链条不断。
> 只有「涌现结论」是新生成的，标 **D 级**。

| 情况 | 信度 |
|------|------|
| 档案 A 的某条目标为 A 级，综合档案引用它 | **A 级**（继承，出处：档案 A §…） |
| 档案 A 标 B 级 | **B 级**（继承） |
| 两份档案对同一问题分别标 A 和 B，综合时 | 取**较低**者（B），并在证据里注明两处出处 |
| 涌现结论（单看任何一份都得不出的） | **D 级**，且 **≤3 条** |

**D 级上限的处理**：涌现结论本身是 D，所以数量必须严控在 3 条以内，否则 `D > 20%` 会触发质检失败。**这是真实信号，不要绕过**——如果一份综合档案的 D 级超标，说明你在靠推断填充，而不是在综合。

---

## 三、独立性规则（最重要）

> **若两份档案的 `sources[]` 有重叠（源自同一批素材），它们不构成独立佐证。**

**为什么**：`distillation-framework.md` 的 `三重验证` 验证1 要求「跨域复现」——在**至少 2 个不同领域**出现。若两份档案其实来自同一批素材，所谓「两人共识」只是**一份素材数了两次**。

**反例**：

| 场景 | 错误结论 | 正确结论 |
|------|---------|---------|
| 芒格档案与巴菲特档案都主要出自《伯克希尔股东信》 | 「两人都认同 X」= 共识 | 只有**一个**独立来源，**不足以**构成共识 |
| 两份档案都引用同一本书 | 同上 | 同上 |

**检测方式**：比对各档案 `manifest.json` 中 `sources[].sha256`。交集非空 → 记录到综合档案的 `source_overlap` 字段：

```json
"source_overlap": [
  {"archives": ["munger", "buffett"],
   "shared": ["sources/books/berkshire-letters.pdf"],
   "verdict": "不构成独立佐证"}
]
```

`scripts/meta_scan.py` 自动做这个检测并输出。

**共识判定的完整条件**：

> 共识 = **≥2 份「来源不重叠」的档案**支持 **且** 各自信度 ≥B

## 四、判定规则

### 4.1 共识

- **≥2 份来源不重叠的档案**支持，各自信度 ≥B
- 写入 `research/01-consensus.md`，条目注明每份档案的出处
- ❌ 不满足独立性条件 → **降级为「单源观察」**，不进共识段

### 4.2 分歧

- **≥2 份来源不重叠的档案**在同一问题上立场对立，各自信度 ≥B
- 写入 `research/02-divergence.md`，标明阵营：`{档案: 立场}`
- **分歧优先于共识**——这是**展示顺序与篇幅**的规定，不是「有分歧就不写共识」：
  - 分歧段排在前、篇幅更大
  - 一份问题可以同时出现在共识段（各方都同意的前提）与分歧段（在前提之上的分歧）
  - ❌ **不要**因为存在分歧就把共识段清空——那是另一种失真

### 4.3 什么是「同一个问题」

脚本**不做**这个判断。`meta_scan.py` 只输出**候选对照矩阵**（按关键词粗聚），「这两条是不是在回答同一个问题」「是不是真的对立」由 **agent 读语义判定**。

这与既有分工一致：脚本做静态机械检查，独立 agent 做语义判断。

## 五、`## 综合` 段（唯一的新内容）

插在「核心骨架」与「矛盾与张力」之间：

```markdown
## 综合

### 互补缺口
- 档案 A 缺「决策记录」，而档案 B 在此维度 coverage 85 —— B 可补 A（出处：A §信息缺口、B §manifest）
- …

### 涌现结论
> 以下为**推断（D 级）**，单看任何一份档案都得不出。

1. [结论] —— 依据：档案 A §… + 档案 B §…
2. [结论] —— 依据：…
（最多 3 条）
```

**互补缺口的判定**：档案 A 的 `gaps` 落在档案 B 的强项维度上（B 的 `dimensions[].coverage` 高）。这是机械可查的，`meta_scan.py` 会给候选。

**涌现结论的纪律**：
- ≤3 条
- **每条必须列依据**（哪几份档案的哪些条目）
- 显式标 D 级
- ❌ 不得是「把共识换个说法」——那叫复述，不叫涌现

## 六、字段诚实性

综合档案的 frontmatter 字段填法（这是它能通过 `quality_check.py` 的关键）：

| 字段 | 填法 |
|------|------|
| `schema` | `topic` |
| `sources_total` | **N**（被综合的档案数） |
| `source_words` | Σ 各档案的 `distillate_words` |
| `distillate_words` | 本综合档案正文字数 |
| `compression_ratio` | `档案总字数:综合档案字数`，即 `N 份档案之和 : 本档` |
| `sources_primary` / `sources_secondary` | **去重叠后**统计各档案的原始来源：一手/二手分别累加，**共享素材只计一次** |
| `dimensions` | 照 topic schema 六维 |
| `gaps` | 综合后的缺口（含「因来源重叠而无法判定」的项） |

`manifest.json` 额外写 `meta_sources: [slug...]` 与 `source_overlap: [...]`。

## 七、执行流程

1. **收集**：用户指定 N 份档案目录（或说「把这几个人综合一下」）
2. **扫描**：`python3 scripts/meta_scan.py <档案目录...> --out distilled/<综合slug>/`
   - 抽取各档案的「主张 + 信度 + 心智模型 + gaps + 维度覆盖」
   - **输出来源重叠检测**
   - 输出候选对照矩阵与互补缺口候选
3. **判定**（agent，语义）：读候选矩阵 → 判定共识 / 分歧 / 断层线
4. **断层线分析**：分歧的根源是**事实分歧**还是**价值观分歧**？后者才是真正的断层线
5. **合成**：按 topic schema 六维 + `## 综合` 段写 `DISTILLATE.md`
6. **质检**：`quality_check.py` + 独立 agent 跑 `quality-scorecard.md`
7. **精炼**：`adversarial-refine.md`

---

## 八、质检清单

- [ ] `schema` 是 `topic`，`schema_version` 仍为 1？
- [ ] `sources_total` = 档案数 N，不是原始素材数？
- [ ] **来源重叠检测跑过了**？重叠的档案**没有**被当作独立佐证？
- [ ] 共识条目都满足「≥2 份**不重叠**档案 + 信度 ≥B」？
- [ ] 分歧段排在共识段之前、篇幅更大？
- [ ] 断层线区分了**事实分歧**与**价值观分歧**？
- [ ] `## 综合` 段的涌现结论 ≤3 条，每条列了依据，都标 D 级？
- [ ] D 级占比 <20%？（超标说明在靠推断填充）
- [ ] `source_overlap` 字段已写入 `manifest.json`？
- [ ] 没有把「一份素材数两次」当成共识？
