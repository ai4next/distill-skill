# 蒸馏质量评分卡（Distill Quality Scorecard）

> 蒸馏档案的出厂质检报告。回答一个问题：**这份档案到底浓不浓、诚不诚实、能不能用？**
>
> 铁律：**蒸馏 agent 和评分 agent 必须是两个独立 agent，绝不自评自证。** LLM 自评质量接近随机水平，自评等于没评。

## 六个维度（总分 100）

| # | 维度 | 分值 | 测什么 | 怎么测 |
|---|------|------|--------|--------|
| 1 | 覆盖度 | 20 | 各维度是否有素材支撑，有没有维度是空的 | 查 `manifest.json` 的 `dimensions[].status` 与 `coverage`：全 complete 且 coverage 均值 ≥70 = 满分；有 missing = 每项扣 7 |
| 2 | 信度 | 20 | 一手占比够不够，D 级推断有没有超标 | 算 `confidence` 分布：A+B 占比 ≥60% 且 D <20% = 满分；D ≥20% 直接 0 分 |
| 3 | 浓度 | 20 | 是不是把摘要当蒸馏交了 | 算「每千字独立条目数」：8-15 条 = 满分；<5 条 = 0 分（没提炼）；>20 条 = 10 分（没展开） |
| 4 | 可溯源性 | 15 | 骨架条目能不能定位回素材 | 随机抽 3 条骨架，要求指出素材出处。3/3 定位到 = 满分；每条失败扣 5 |
| 5 | 矛盾保留 | 15 | 有没有把矛盾调和掉 | 检查矛盾段：有矛盾且分了类型（时间性/领域性/本质张力）= 满分；出现「虽然…但是…」式和稀泥 = 0 分；素材确实无矛盾 = 8 分 |
| 6 | 缺口诚实 | 10 | 不知道的有没有说不知道 | `gaps` 存在且与正文一致 = 满分；`gaps` 为空但存在 coverage<40 的维度 = 0 分（装懂） |

> **`coverage` 为 `null` 表示「未回填」——不是 0 分，也不是满分。**
> 遇到 `null` 的正确动作是**先让 agent 回填**（那是 Phase 3 的判定结果），再评分。
> 拿 `null` 当 0 会误判「覆盖度不足」，当满分则是装懂。
> 同理，`sources_primary` / `sources_secondary` 为 `null` 时第 2 项的「一手占比」无法计算。
> `quality_check.py` 会把所有未回填项列进**软诊断**，评分前先看那一栏。

## 等级

| 等级 | 分数 | 含义 |
|------|------|------|
| A | ≥85 | 出厂即精品，可直接交付使用 |
| B | 70-84 | 合格，个别维度有已标注的薄弱点 |
| C | 55-69 | 能用但需谨慎，缺口段必读 |
| D | <55 | 不建议使用，需回炉重蒸或补素材 |

**B（70 分）是可用门槛。** 低于 B 的档案不应作为下游产物的输入。

## 执行流程

0. **先过静态关**：`python3 scripts/quality_check.py <档案目录>`（7 项硬检查 + 软诊断）。
   结构不过就先修结构，不要带着缺段落进评分卡——那只会浪费一次评分。
   软诊断里的「未回填」项要先回填，否则本卡的第 1、2 项无法评。
1. **出题**（出题 agent，或主 agent）：
   - **3 道生成力题**：选素材中**未直接讨论过**但相关的 3 个问题。测骨架能不能推断新立场——这是蒸馏与摘要的分水岭
   - **1 道缺口题**：问一个素材明确没覆盖的问题。期望档案使用者回答「这超出档案范围，档案标注的缺口包括…」，而不是硬答
   - **1 道溯源抽查**：随机抽 3 条骨架条目，要求给出素材出处
2. **答题 agent**：只读 `distilled/<slug>/` 内的文件，禁止联网，禁止补充训练语料中的知识
3. **评分 agent**：独立 agent，拿到答题结果 + 本 rubric + 档案路径 + 原始素材，逐维打分
4. **产出**：档案目录下生成 `QUALITY.md`

## 反作弊

- 答题 agent **不知道**自己在被测什么维度
- 评分 agent **不参与**蒸馏过程，只对照原始素材
- 出题**避开**档案正文里已有的示例（防止背答案）
- 溯源抽查的条目**随机抽取**，不固定
- 分差 >10 分时建议换第二个评分 agent 复核

## 与 distill 流程的关系

- Phase 5 的「独立质检」执行本评分卡
- 得分 <70 → 回到 Phase 2/3 补维度或补素材，**不要靠加长正文刷分**
- **迭代上限 2 轮**：两轮后仍 <70，在 `QUALITY.md` 与 `gaps` 中如实标注薄弱维度，交付当前最优版本——诚实标注的 60 分档案，好过看起来完美的编造档案
